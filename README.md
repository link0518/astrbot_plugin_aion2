# astrbot_plugin_aion2

AION2（永恒之塔 2）国际服查询插件。角色、装备、道具、公告、排行一次查全，**界面与输出为简体中文**。

默认查日服（`asia` 分片），可在配置里切到美东、美西、欧服、南美服。

## 功能

| 能力 | 说明 |
| --- | --- |
| 角色档案 | 等级、职业、战斗力、属性、称号收集、守护者板进度 |
| 装备面板 | 各部位装备（含强化等级）、时装、宠物、翅膀、技能 |
| 道具详情 | 品级、装备等级、魔石/神石孔位、主属性浮动区间、可用职业、外观 |
| 服务器 / 职业 | 列出当前区域的全部服务器与职业，附搜索用 ID |
| 官方公告 | 公告、更新公告、开发日志 |
| 排行榜 | 深渊、噩梦、超越、竞技场等（官方当前已关闭公开数据） |
| 活动时刻表 | 时空裂隙、小游戏、次元入侵、重置时刻，本地推算，并可订阅开场提醒 |
| 配置面板 | 在 WebUI 里改配置、看运行状态、管理提醒订阅、预览时刻表、自检连通性 |

提供两种用法：**指令**（`角色 mizoo`，带不带斜杠都能触发）与**自然语言**（注册为大模型工具，直接问「mizoo 的战力多少」）。

## 安装

克隆到 AstrBot 的插件目录：

```bash
cd AstrBot/data/plugins
git clone https://github.com/link0518/astrbot_plugin_aion2.git
```

也可以在 WebUI 插件管理页用仓库地址安装。装好后重载插件即可。

依赖会随 `requirements.txt` 自动安装：

```
httpx        # 异步 HTTP
zhconv       # 繁体转简体
```

图片卡片依赖 AstrBot 自带的 Playwright 文转图能力。**没有装也能用**：渲染失败会自动回退为纯文本输出。

## 指令

```
角色 <角色名> [服务器ID]    角色档案
装备 <角色名> [服务器ID]    装备面板
道具 <道具ID>               道具详情
服务器                      服务器列表
职业                        职业列表
公告 [板块]                 官方公告
排行 [榜单]                 排行榜
活动 [明天]                 活动时刻表
活动 订阅 / 退订 / 状态      活动开场提醒
区域                        查看当前查询区域
帮助                        用法
```

指令**不需要斜杠**，直接发：

```
角色 mizoo
装备 mizoo 1501
道具 110160008
服务器
公告 更新公告
```

带斜杠（`/角色 mizoo`）同样可用。触发要求整条消息正好是这个句式，
免得群里闲聊提到「角色」二字就被拦下来；不放心可以在配置里关掉 `free_trigger`。

- 角色名重名时，插件会列出候选（含职业、种族、服务器），**回复序号**即可继续查询，10 秒内有效；
  也可以直接带上服务器 ID（`角色 mizoo 1501`）。候选按会话与发送者区分，别人替你回复无效。
- 板块：公告、更新公告、开发日志、综合讨论、军团招募、攻略、图文。
- 榜单：深渊、噩梦、超越、孤独竞技场、协力竞技场、升天试炼。
- 板块与榜单的名称**中英文都可用**：`公告 更新公告` 与 `公告 update` 等价。
- `帮助` 另有 `help` 别名。

## 活动时刻表与提醒

`活动` 输出今日时刻表卡片（`活动 明天` 看次日；渲染不可用时回退纯文本）。时刻表**全部本地推算**——官方接口没有日程类端点，数据来自客户端与社区实测：

| 活动 | 频率 | 北京时间 |
| --- | --- | --- |
| 时空裂隙 | 每 3 小时 | 02:00 / 05:00 / 08:00 / 11:00 / 14:00 / 17:00 / 20:00 / 23:00 |
| 小游戏（Shugo Festival） | 每半小时 | 每小时 :15、:45 各一场，两组游戏固定对应 |
| 次元入侵 | 每小时 | :30 |
| 重置 | 每日 / 每周三 | 15:00 |

**时间对所有分片是同一个物理时刻。** 裂隙在墙钟上锚定 UTC 每 3 小时的整点，所以美东看到「02:00 起每 3 小时」、日服看到「09:00 起每 3 小时」，其实是同一场；插件统一按北京时间展示，与 `region` 配置无关。

### 提醒怎么开

默认**不推送**，需要在会话里订阅：

```
活动 订阅      # 本会话开始接收开场提醒
活动 退订      # 取消
活动 状态      # 查看订阅状态
```

订阅后，每场活动开始前 5 分钟（可配）推一条纯文本提醒，**正文同时带裂隙与小游戏**——裂隙那条会附上紧接着的小游戏窗口与当组游戏名，小游戏那条会附上下一次裂隙时间。

订阅记录与已推记录落在 `data/plugin_data/astrbot_plugin_aion2/` 下的 `event_subs.json`、`event_sent.json`，重启后订阅不丢、同一场不会重发。提醒是静态时刻表推算，不是官方状态推送，临时调整不会同步。

## 配置面板

插件在 AstrBot WebUI 里自带一个控制台页面（插件的 Plugin Pages）。打开方式：**插件管理 → 插件详情页 → 控制台**。

控制台依赖 AstrBot 的 Plugin Pages 能力，需要 **AstrBot 4.24.1 及以上**。更低版本上插件照常加载与查询，只是看不到这个页面。

面板分三页：

| 页面 | 内容 |
| --- | --- |
| 运行状态 | 当前区域、提醒开关与后台循环、订阅会话数、缓存条数、下一次裂隙与小游戏倒计时；一键连通性自检、分别清空结果缓存与译名缓存；订阅列表可发测试消息或直接移除 |
| 配置项 | 按「查询区域 / 输出与展示 / 触发方式 / 中文化 / 活动提醒 / 网络与缓存」分组的可视化表单，带范围校验、「已改」标记、按组恢复默认 |
| 活动时刻表 | 今日 / 明日时刻表：24 小时时间轴、8 场裂隙的状态、小游戏两组名单、重置时刻 |

面板读的是插件自己的 `_conf_schema.json`，所以新增配置项会自动出现在表单里。写入走服务端校验——类型、范围、选项、`HH:MM` 格式都在插件侧重新过一遍，不信任前端传来的值。保存后立刻生效：**查询区域、限流、超时、缓存时长、中文化开关会重建连接**；提醒相关项同步到后台循环；繁转简与译名缓存时长就地更新。切页不会丢改动，未保存时底部一直有提示。

页面本身是零依赖的原生 HTML/CSS/JS，跟随 WebUI 的亮暗主题，不联网加载任何外部资源。

## 配置

面板之外，这些选项也可以直接在 WebUI 的插件配置里改（两边改的是同一份数据）：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `region` | `asia` | 查询区域：`asia` 日服、`nae` 美东、`naw` 美西、`eu` 欧服、`sa` 南美服。各分片的服务器与角色互相独立 |
| `output_mode` | `image` | `image` 图片卡片，`text` 纯文本 |
| `free_trigger` | `true` | 是否支持不带斜杠的写法 |
| `event_push` | `true` | 活动提醒总开关 |
| `event_lead` | `5` | 每场活动提前几分钟推送（1–60） |
| `event_remind_rift` | `true` | 是否推时空裂隙（8 场/天） |
| `event_remind_minigame` | `true` | 是否推小游戏（48 场/天，嫌吵可关） |
| `quiet_start` | `00:00` | 静默时段开始，留空表示不静默 |
| `quiet_end` | `08:00` | 静默时段结束，可与开始时间跨零点 |
| `chinese_names` | `true` | 按道具 ID 从台服反查中文（名称、品类、种族、外观、主属性名） |
| `t2s` | `true` | 台服返回的是繁体，输出前转简体 |
| `rate_limit` | `5.0` | 每秒请求上限，不建议调高 |
| `request_timeout` | `15` | 单次请求超时秒数 |
| `cache_ttl` | `600` | 接口结果缓存秒数 |
| `glossary_ttl` | `2592000` | 中文译名缓存秒数，默认 30 天 |
| `max_list_items` | `10` | 列表最多显示条数 |
| `image_width` | `720` | 卡片宽度 |

译名缓存落在 `data/plugin_data/astrbot_plugin_aion2/glossary.json`，跨重启复用。

大模型工具（`aion2_*`）由 AstrBot 装饰器自动注册，没有插件内的开关；如需关闭，用 AstrBot 的「工具管理」页面单独禁用。

## 区域说明

AION2 只有韩服、台服、国际服三套站点，国际服内部再分五个分片。

**区域只决定「查哪个分片」，不决定语言。** 各分片的服务器与角色互相独立——同一个名字可能在不同分片各有一个角色，所以查某个角色必须先选对分片。而接口语言由插件固定为英文（台服为繁中），中文一律本地映射：`Siel` → 希埃尔、`Ranger` → 弓星，与所选区域无关。

**日服不是独立站点，而是 `asia` 分片**：同一个 `aion2.plaync.com`，只是它面向日本运营。查它同样走英文（`en-US`），拿到的是 `Siel`、`Nezekan` 这些英文名，**不需要也不使用日语数据**——带 `ja-JP` 只会让服务器名变成 `シエル`、`ネザカン`，和词表对不上，反而绕远路。

| 配置值 | 显示名 | 上游分片参数 | 服务器（天族 + 魔族） | ID 段 |
| --- | --- | --- | --- | --- |
| `asia` | 日服 | `as` | 18 + 18 | 1501-1518 / 2501-2518 |
| `nae` | 美东 | `nae` | 8 + 8 | 1101-1108 / 2101-2108 |
| `naw` | 美西 | `naw` | 5 + 5 | 1201-1205 / 2201-2205 |
| `eu` | 欧服 | `eu` | 22 + 22 | 1301-1322 / 2301-2322 |
| `sa` | 南美服 | `la` | 6 + 6 | 1401-1406 / 2401-2406 |

各分片的服务器数量并不相同（美西只有 5 个，欧服有 22 个）。注意**配置值与上游分片参数不总是同名**：南美服的参数是 `la`、日服是 `as`，传错成 `asia` 之类的值也不会报错，而是静默返回默认分片的数据——所以插件内部只从区域定义取参数，不接受手工填写。

国际服**没有任何中文 locale**（只有英/德/西/法/日/葡），所以中文一律由插件补齐。既然哪个语言的原文都要过一遍映射，插件就固定用英文取数——它的服务器名、职业名、品级名都能直接命中词表，是映射成本最低的一种。

## 中文化是怎么做的

分四层：

1. **固定术语查词表** —— 职业、属性、装备部位、品级、服务器名、守护者板名。
   词表里的中文取自**台服接口返回的官方译名**，再转简体，不是机器直译。
   服务器名覆盖台服全部 36 个（两族各 18）；日服、欧服的前 18 位与它按位置一一对应，
   而位置顺位另有日服片假名读音交叉验证（`ババルン` ↔ 台服「巴巴隆」↔ 国际服 `Baba`）。
2. **职业按 pcId 解码** —— 角色接口给的是 `pcId`，它是「职业 × 性别 × 种族」的编码
   （`5-8` 剑星、`13-16` 弓星、`45-48` 拳星…），与职业列表接口的 `id`（`2-12`）**不是一套编号**。
   映射固化在词表里，取自台服 `pcdata` 接口。
3. **动态文本繁转简** —— 台服中文内容统一转简体。
4. **道具按 ID 反查台服** —— 各区道具 ID 通用，用 ID 去台服取中文信息：名称、品类、可用种族、外观、主属性名
   （如 `Training Greatsword` → `训练用巨剑`，`Attack` → `攻击力`），结果落本地缓存。

另外，上游的搜索结果会把名字里的命中片段包成 `<strong>mizoo</strong>`，插件在解析时就地去掉标签、
还原 HTML 实体，不会把标记发给用户。

### 中文化的边界

**只借用台服的名称，不借用台服的数值。** 两区版本不同步，同一道具的属性数值会不一致
（示例：台服 `110160008` 攻击力 `9~12`，国际服是 `4~6`）。因此道具卡上的数值一律取本区，
只有名称类字段来自台服。

以下内容官方没有任何中文来源，插件保留原文，不做臆造翻译：

- **技能名**（如 `Snipe`）—— 官方没有技能字典接口。日服能给出日语名（`狙撃`），但那是日语不是中文
- **宠物名、翅膀名** —— 它们的 ID 不属于道具体系，台服反查不到（返回 `id=0`）
- **时装外观道具名** —— 这类 ID 在台服道具库中不存在
- **称号名** —— 角色档案里有 `titleId`，但官方没有称号字典接口，也没有别的中文字典可用
- **欧服独有的 8 个服务器**（`Ishtar`、`Tiamat`、`Fafnir`、`Indnath`…）—— 台服只开到 18 个服，
  这 8 个在台服没有对应条目，`服务器` 会保留英文并在列表末尾说明
- **韩服专属内容** —— 韩国站点对境外请求返回错误页

上面几项在卡片上会标注「官方未提供中文名」，装备名、道具名缺失时则回退显示原文。

## 已知限制

- **排行榜**：NC 已关闭公开榜单接口，目前查询会提示「官方已关闭」，功能保留待其恢复。
- **社区板块**：国际服各分片共用同一套社区数据，目前只有官方公告在更新，攻略、图文、军团招募等板块都是空的。
- **道具只能按 ID 查**：没有按名搜索的道具目录。可以从角色装备面板里拿到道具 ID 再查详情。
- **首次查询要反查译名**：查一个角色的装备需要反查约 20~35 个道具译名，约 4~6 秒；之后走缓存是瞬时的。
- **道具接口不分分片**：官方道具库是全局数据，且 `asia` 分片带上 `region` 参数会返回空的 200 响应，
  因此插件请求道具时固定不带分片参数。
- **活动时刻表是本地推算**，不是官方状态推送：官方若调整时间（小游戏的 :15/:45 轮换就调过一次），
  需要更新插件；表集中在 `core/events.py` 顶部，改一处即可。
- **小游戏名保留英文**：官方没有中文来源，九个小游戏的名字按原文显示，不臆造译名。

## 数据来源与致谢

数据来自 NCSoft 的 AION2 官方站点公开接口，属于非官方、只读的用法。

接口的路径规则、数据结构与能力边界参考了开源项目
[**nuriland/aion2-api**](https://github.com/nuriland/aion2-api)（MIT License，作者 nuri）。
本插件用 Python 重写了客户端部分，并额外实现了中文化层与卡片渲染。

台服的译名同样来自官方站点，仅作为中文对照使用。

## 测试

```
python tests/test_offline.py        # 离线：路由、中文化、模型解析、卡片上下文、配置校验
python tests/test_plugin_smoke.py   # 冒烟：模拟 AstrBot 加载插件、跑通指令与配置面板接口
python tests/test_live.py           # 联调：真实接口，卡片 HTML 输出到 tests/out/
python tests/render_events.py       # 离线生成活动时刻表卡片的 HTML（按当前时间）
python tests/render_preview.py      # 把 tests/out/ 的卡片截成 PNG，检查外观
python tests/webui_preview.py       # 用假 bridge 起本地预览，把配置面板截成 PNG
```

前两项不联网，可在任何环境运行。`test_live.py` 与两个截图脚本需要能访问官方站点与 Playwright。
